# D2F authentication image assets

Current direction: high-quality shipping photography on splash and signup, and the exact world-map artwork from the supplied October 21 reference above Welcome Back. Forms use navy type, gold actions, light surfaces and no decorative drop shadows. See `home-refresh-notes.md` for the latest home cards, splash copy and route planner.

All final artwork was created with the built-in image_gen tool and copied into the workspace. Photo assets are optimized as high-quality JPEGs; original generation outputs remain in the tool's default generated_images directory.
